 Control ASV - Embarcación Autónoma 

Este repositorio contiene el paquete principal de ROS 2 para el control de una embarcación autónoma de pequeño porte, destinada principalmente a tareas de observación y medición de parámetros medioambientales.

Hardware Soportado
* **Controlador de Vuelo:** Placas compatibles con PX4 (familia Pixhawk 6C/6X o CUAV V5/V7 Nano).
* **Propulsión:** 2 propulsores eléctricos Blue Robotics T200.
* **Alimentación:** 2 baterías LiPo 3S 9000 mAh.
* **Sensores previstos:** GPS/GNSS y sensores medioambientales.

 Requisitos del Sistema
* Ubuntu 24.04 LTS (Nativo o vía WSL2)
* ROS 2 Jazzy Jalisco
* Micro XRCE-DDS Agent
